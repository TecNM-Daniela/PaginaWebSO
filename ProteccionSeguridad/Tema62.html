Clasificación aplicada a la seguridad

Tipos de seguridad y medidas que ayudan a proteger los equipos, los datos y las comunicaciones.

¿Cómo se clasifica la seguridad?

La seguridad informática puede organizarse en diferentes categorías según el elemento que se desea proteger. Cada una utiliza medidas específicas, pero todas trabajan en conjunto para reducir los riesgos dentro de una organización o sistema.

🏢

1. Seguridad física

Protege los equipos, instalaciones y dispositivos contra daños, robos o accesos físicos no autorizados.

Ejemplos:
  • Cámaras de vigilancia.
  • Puertas con acceso controlado.
  • Alarmas y protección eléctrica.
🔒

2. Seguridad lógica

Protege los programas, archivos, cuentas y datos mediante controles establecidos por software.

Ejemplos:
  • Contraseñas y autenticación.
  • Permisos de archivos.
  • Antivirus y firewalls.
📋

3. Seguridad administrativa

Establece políticas, responsabilidades y procedimientos para el uso correcto de los recursos tecnológicos.

Ejemplos:
  • Reglas para crear contraseñas.
  • Capacitación de usuarios.
  • Políticas de respaldo de información.
🌐

4. Seguridad de red

Protege la comunicación y el intercambio de información entre computadoras y otros dispositivos.

Ejemplos:
  • Firewalls de red.
  • Conexiones cifradas.
  • Monitoreo del tráfico de red.

Clasificación según el momento de protección

Prevención

Medidas que buscan evitar que ocurra un incidente, como utilizar permisos y actualizar el sistema.

Detección

Herramientas que identifican actividades extrañas, como alertas y registros del sistema.

Recuperación

Acciones para restaurar los servicios y la información después de un problema.

Ejemplo de aplicación

En una empresa, la seguridad física puede aplicarse mediante cámaras y controles de entrada; la seguridad lógica, mediante cuentas de usuario y permisos; la administrativa, mediante políticas internas; y la seguridad de red, mediante firewalls y conexiones protegidas.

Ninguna clasificación funciona de manera aislada. La combinación de las diferentes medidas permite obtener una protección más completa.
