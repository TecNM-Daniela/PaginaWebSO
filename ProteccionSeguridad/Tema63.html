UNIDAD 3 · TEMA 6.3

Funciones del sistema de protección

Mecanismos que controlan el acceso de usuarios y programas a los recursos del sistema.

¿Qué hace un sistema de protección?

El sistema de protección de un sistema operativo administra los permisos y establece límites para que los usuarios y procesos solamente puedan realizar las operaciones que tienen autorizadas. De esta manera, ayuda a evitar que un programa interfiera con otros o que un usuario modifique información que no le corresponde.

Funciones principales

👤
Identificación

Permite reconocer qué usuario o proceso está solicitando utilizar un recurso.

🔍
Autenticación

Comprueba la identidad del usuario mediante contraseñas, códigos u otros métodos.

🛡️
Autorización

Determina qué acciones puede realizar una persona después de identificarse.

🔑
Control de acceso

Permite o rechaza las solicitudes de acuerdo con los permisos establecidos.

📋
Auditoría

Registra actividades importantes para revisar quién utilizó un recurso y cuándo lo hizo.

📦
Aislamiento

Evita que los procesos interfieran indebidamente con otros procesos o con el sistema operativo.

Proceso de control de acceso

Cuando una persona intenta utilizar un archivo o programa, el sistema realiza una serie de comprobaciones antes de permitir la operación.

01. Solicitud

El usuario intenta abrir o modificar un recurso.

02. Identidad

El sistema reconoce y verifica al usuario.

03. Permisos

Se revisan los permisos asignados al usuario.

04. Resultado

Se permite o se rechaza la operación.

Ejemplo práctico

Cuando un estudiante inicia sesión en una computadora, el sistema verifica su cuenta. Después, le permite acceder a sus documentos y aplicaciones autorizadas. Si intenta instalar un programa y no cuenta con permisos de administrador, el sistema puede impedir esa acción.

Las funciones de protección trabajan en conjunto para mantener controlado el uso de los recursos y reducir los accesos indebidos.
